# Data Annotation Portfolio

**Data Collection | Data Annotation | Dataset Preparation | Quality Assurance**

Welcome to my data annotation portfolio! I am a Computer Science graduate building practical experience in preparing, annotating, organizing, and validating datasets across different domains.

This portfolio showcases hands-on projects involving Urdu OCR, object detection, and speech intelligence.

## Featured Projects

### 1. Urdu Orator OCR Dataset
**Domain:** Optical Character Recognition (OCR) and Urdu text annotation

A dataset collection and annotation project supporting Urdu OCR research. Includes printed, handwritten, camera-captured, and historical Urdu text categories.

[View Project Repository](https://github.com/Areeba-Naeem123/Urdu-Orator-OCR-DataSet)

### 2. Everyday Object Detection
**Domain:** Image Annotation and Object Detection

A 24-image object detection dataset annotated with bounding boxes using CVAT and exported in Ultralytics YOLO format.

**Classes:** Cup, Mobile Phone, Bottle

[View Project Repository](https://github.com/Areeba-Naeem123/Everyday-Object-Detection)

### 3. Urdu-English Speech Intelligence Dataset
**Domain:** Speech Annotation and Natural Language Processing

A speech annotation project featuring a 20-recording Urdu sample sourced from Mozilla Common Voice. Includes human-verified transcripts, speaker identification, language identification, sentiment labels, and named entity annotations.

English and Urdu-English code-switching are planned extensions.

[View Project Repository](https://github.com/Areeba-Naeem123/Urdu-English-Speech-Intelligence-Dataset)
